# PPTReader

在 Mac 上看课件，让读过整份课件的 AI 给你讲；上课时录下来，课后整理出课件上没有的内容和课程安排。

[English](README.md) · **中文**

PPTReader 是一个原生 macOS 应用。打开课程文件夹，就能一边翻 PDF、PowerPoint、Word 课件，一边向 AI 提问：它读过整份课件，也看得到你正在看的那一页。

## 能做什么

**看课件时**

- 按 ⌘E 讲解当前页；选中文字，或按住 Shift 框住图表、公式，让它解释、翻译、举例；也可以直接提问（⌘L）。
- 回答里的公式、代码、表格、流程图都能正常显示；图表可以放大预览、导出成图片。
- 可以设成翻页时自动讲解；讲解的篇幅、图示和例题多少都能调。

**复习时**

- **学习路线图**（⇧⌘M）：把课件整理成一张知识结构图，问过的页标成已覆盖，还没看的部分一眼就能看出来。
- **学习档案**：写下你的专业、基础和这门课的要求，讲解会照着来；对话太长时，前面的内容会整理成学习记录，不会忘掉讲过什么。
- **学习统计**：阅读时长、提问次数、Token 用量和花费，按天、课件、课程查看。

**上课时**（macOS 26 及以上）

- 按 ⇧⌘R 开始录音，在本机离线转写，录音不会上传；可以打开实时字幕。
- 课后点「AI 整理」：纠正转写里听错的术语，找出**老师讲了、课件上没有的内容**和**课程安排**（考试、作业、截止日期……），并按课程编号打上标签。
- 整理出的要点会显示在课件对应页的页边，点一下就跳回录音里的那一刻。

## 快速开始

1. 从[最新发布页](https://github.com/XYoungSky/PPTReader/releases/latest)下载 `PPTReader-vX.Y-macOS-arm64.zip`，解压后把 `PPTReader.app` 移入「应用程序」。应用没有经过 Apple 公证，第一次打开被拦截时，到「系统设置 → 隐私与安全性」里点「仍要打开」。
2. 按 ⌘O 打开课程文件夹。课程文件夹是只读的，PPTReader 不会改动里面的任何文件。
3. 打开「设置 → 模型」，添加一个服务商，填上 API Key，点「测试连接」后选一个模型。
4. 打开一份课件，按 ⌘E。

**系统要求**：Apple Silicon Mac，macOS 14 及以上；课堂录音需要 macOS 26 及以上。打开 PPT / Word 需要本机装有 Microsoft Office，PDF 不需要。升级时，设置、API Key、对话、统计和录音都会保留。

## 模型和服务商

支持任何 OpenAI 格式的接口。「添加服务商」里有这些模板，最多可以保存 5 个，在 AI 面板顶部的模型菜单里随时切换：

| 模板 | API 地址 | 说明 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | 可以开关深度思考 |
| Kimi Code（会员订阅） | `https://api.kimi.com/coding/v1` | 海外账号用 `api.kimi.ai`；可以调思考强度。会员权益面向编程，被拒绝（403）时改用开放平台的 Key |
| Kimi 开放平台 | `https://api.moonshot.cn/v1` | 默认把缓存保留 1 小时，连续提问更省钱 |
| OpenRouter | `https://openrouter.ai/api/v1` | 一个 Key 用各家模型；模型菜单可以搜索、显示价格；Claude 模型也能命中缓存；可以只用不收集数据的服务商 |
| 其他 | 自己填写 | Ollama、LM Studio 等本机服务可以不填 Key |

- **按任务选模型**：讲解用强模型，整理学习记录、判断课件这类杂活用便宜的轻量模型。在「设置 → 模型 → 按任务选择模型」里单独设置，没设置的都跟随讲解用的模型。
- **省钱**：请求按服务商的缓存来组织，连续提问时课件部分大多按缓存价计费；AI 面板顶部的小圆环会显示用了多少上下文、缓存命中了多少。
- **自动适应**：模型不支持图片、上下文比预期短、某个参数不被接受时，PPTReader 会记下来，下次不再犯；限流和临时故障会自动重试。

## 课堂录音

需要 macOS 26 及以上，第一次录音时会请求麦克风权限。

1. **录音**：点工具栏的麦克风，或按 ⇧⌘R。课件下方会出现录音条，显示时长和音量，可以暂停、停止、打开实时字幕。录音按 5 分钟一段保存，应用意外退出最多丢正在录的那一段；默认录满 3 小时自动停止，提前 5 分钟提醒。
2. **转写**：每段录完就在本机转写。可以选口音（美式、英式、澳式等英语，或普通话）和识别方式：
   - **标准**：系统识别，速度快；
   - **听写**：参考课件里的术语，适合安静、离得近的场合；
   - **Whisper**：OpenAI 的开源模型，在本机运行。口音重、离得远、有杂音时明显更准，需要先在「设置 → 课堂录音」下载约 650 MB 的模型，第一次使用要准备几分钟。15 分钟的录音大约 1–2 分钟转完。

   已有的录音可以在「课堂录音」窗口的「⋯ → 重新转写」里换一种方式重新转写。
3. **回放**：在「课堂录音」窗口（⌥⌘R，或侧栏左下角的按钮）里，录音按课程编号分组，可以搜索。播放时转写跟着高亮，点任意一句就从那里播放。
4. **AI 整理**：点一下，依次完成三步：
   1. 判断这节课讲了课程文件夹里的哪几份课件，列出来让你确认，并给录音打上课程编号（如 ADS205）；
   2. 参照课件纠正转写里听错的词，生成「纠正版」，改过的地方标出来；
   3. 找出课件上没有的内容（对应到课件的页）和课程安排。
5. **在课件上看**：有页码的要点会显示在课件对应页的页边，点一下跳到录音里的那一刻。可以导出一份带批注的 PDF，原文件不变。

也可以导入手机等其他设备录的音频或视频（「录音 → 导入音频…」，或「课堂录音」窗口左上角的按钮），之后的转写和整理与录音相同，原文件不变。

转写、纠正版、补充要点、课程安排都可以导出（文本或 Markdown）。录音的选项在「设置 → 课堂录音」：转写语言、识别方式、音质（3 小时约 46 或 90 MB）、时长上限，以及录音占用的空间。

## 快捷键

都可以在「设置 → 快捷键」里修改。

| 操作 | 快捷键 | 操作 | 快捷键 |
|---|---|---|---|
| 讲解当前页 | ⌘E | 打开课程文件夹 | ⌘O |
| 提问 | ⌘L | 上一页 / 下一页 | ⌥⌘↑ / ⌥⌘↓ |
| 停止生成 | ⌘. | 放大 / 缩小 / 适合窗口 | ⌘= / ⌘- / ⌘0 |
| 学习路线图 | ⇧⌘M | 显示 / 隐藏侧栏 | ⌃⌘S |
| 学习统计 | ⇧⌘S | 显示 / 隐藏 AI 面板 | ⌥⌘0 |
| 开始 / 停止录音 | ⇧⌘R | 课堂录音窗口 | ⌥⌘R |

## 隐私与数据

- 课程文件夹只读。PPTReader 生成的数据都放在 `~/Library/Application Support/PPTReader`（对话、统计、路线图、录音）和 `~/Library/Caches/PPTReader`（转换和文字缓存）；API Key 存在系统钥匙串里。
- 提问时发给模型服务的是：课件文字、当前页码和截图、选中的内容、最近的对话。
- 录音和转写只在本机。只有点「AI 整理」时，才会把转写和你勾选的课件文字发给模型。
- 学习统计只保存在本机，可以在「设置 → 数据」里清除；录音可以在「课堂录音」窗口里删除。

## 常见问题

**每次升级都要允许访问钥匙串？** 从 2.0 起，安装包用固定的证书签名，从 1.9 升级时最后问一次，之后不再问。自己从源码构建的，见下面的签名说明。

**扫描版的 PDF 能用吗？** 能。没有文字层的页会自动做文字识别（OCR），识别时课件下方会显示进度。

**菜单里的「录音」是灰的？** 课堂录音用的是系统的离线语音识别，需要 macOS 26 及以上。

**怎么看用了多少钱？** 学习统计里有每天、每个任务的 Token 用量；用 OpenRouter 时还会显示实际花费。

## 从源码构建

需要 Xcode 命令行工具（`xcode-select --install`）。

```bash
./scripts/build-app.sh            # 生成 build/Products.noindex/PPTReader.app
./scripts/build-app.sh --install  # 直接安装到 /Applications
./scripts/test.sh                 # 运行测试
```

默认用临时签名（ad-hoc），每次重新构建，macOS 都会当成新应用，重新询问钥匙串和麦克风权限。运行一次 `./scripts/signing.sh create` 生成自签名证书，之后的构建都用它签名；`./scripts/signing.sh export` 可以导出备份，换电脑打包时导入。

```
Sources/PPTReader/
  App/        应用入口、菜单命令
  Models/     全局状态、当前课件、对话、路线图、课堂录音的数据和整理流程
  Services/   模型接口、提示词、Office 转换、文字提取和 OCR、设置、统计、录音、转写、回放、课件批注
  Views/      主窗口、侧栏、阅读区、AI 面板、录音条、统计、路线图和课堂录音窗口
    Settings/ 设置窗口，每页一个文件
Resources/Web/  回答渲染、图表预览、路线图、课堂录音窗口（第三方库离线打包在 vendor/）
Tests/          Swift Testing 测试
scripts/        构建、测试、签名、下载第三方库、生成图标
```
