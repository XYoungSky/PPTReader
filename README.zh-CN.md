# PPTReader

轻量的 macOS 课件伴读应用：一边看课件，一边让读过整份课件的 AI 为你讲解。

[English](README.md) · **中文**

## 功能

- **边看边问**：支持 PDF、PowerPoint、Word（PPT/Word 由本机 Office 转换，原文件不会被修改）。
- **懂上下文**：每次提问都会附上整份课件的文字、当前页码、选中内容和当前页截图。
- **多种提问方式**：讲解本页 · 对选中内容解释 / 翻译 / 举例 · 自由提问 · 翻页自动讲解。
- **完整渲染**：Markdown、LaTeX 公式、代码、表格、SVG、Mermaid、行内 HTML。点按图表可放大预览（捏合或 ⌘ 滚轮缩放、拖动平移），并可拷贝或存储为 PNG。
- **讲解风格**：分别选择篇幅、图示和例题的多少，也可以写下自己的要求（如“推导写完整”“术语附英文”）；在 AI 面板「更多」菜单中可直接打开。
- **学习统计**：按天、课件、课程和模型统计阅读时长、阅读页数、讲解与提问次数和 Token 用量（7 天 / 30 天 / 全部），并以 GitHub 式热力图展示过去一年；每份课件标明所属课程文件夹，已有对话会自动计入。
- **学习档案与学习记录**：在「设置 → 学习档案」里写「关于我」（所有课件通用）和「课程说明」（按课程文件夹），都会放进系统提示。对话超出上下文上限时，较早的对话先整理成学习记录再丢弃，模型仍然记得讲过什么、你在哪里卡住、用过哪些例子。课程文件夹本身不会被修改。
- **上下文用量**：AI 面板顶部的小圆环显示上一次请求占用了多少上下文窗口；点开可以看到写作说明、学习档案、课件、学习记录、历史、本轮提问、截图各占多少，以及缓存命中、缓存写入，缓存可能已过期时也会提示。
- **省 Token**：请求按服务商的前缀缓存来组织（系统提示固定且与课件无关的说明在前、课件在后，历史只追加不改写，按边界固定的块截断），连续对话、OCR 进行中、长课件翻页时，课件和历史大多能命中缓存。
- **自定义快捷键**：在「设置 → 快捷键」中修改所有菜单命令的快捷键。
- **兼容任意 OpenAI 格式接口**，针对 DeepSeek 优化（`deepseek-flash` 支持识图，`deepseek-v4-pro`，可开关深度思考），支持 Kimi Code 会员订阅（可调思考强度）。
- **多个服务商**：最多保存 5 组接口配置，在设置或 AI 面板的模型菜单中一键切换。
- 中英文界面、浅色 / 深色模式，原生应用约 7 MB。

## 环境要求

- macOS 14 及以上
- Xcode 命令行工具：`xcode-select --install`
- Microsoft PowerPoint / Word：仅打开 `.ppt(x)` / `.doc(x)` 时需要

## 构建

直接使用：从 [v1.6 发布页](https://github.com/XYoungSky/PPTReader/releases/tag/v1.6) 下载 `PPTReader-v1.6-macOS-arm64.zip`，解压后将 `PPTReader.app` 移入「应用程序」。此安装包需要 Apple Silicon Mac 和 macOS 14 及以上版本。应用采用本地临时签名，未经 Apple 公证，首次打开可能被 macOS 拦截。

从源码构建：

```bash
./scripts/build-app.sh            # 生成 build/Products.noindex/PPTReader.app
./scripts/build-app.sh --install  # 同时安装到 /Applications
```

## 配置

打开 **设置**（⌘,）→ **模型**。点「添加服务商」可从模板新建（最多 5 个），点按列表中的服务商即可切换；下方编辑的是正在使用的服务商：

| 项目 | 填写 |
|---|---|
| 名称 | 便于区分的名字 |
| API 地址 | 如 `https://api.deepseek.com` |
| 接口类型 | 由模板或认得出的地址自动设置，决定是否发送 DeepSeek 深度思考、Kimi Code 思考强度等参数；经代理访问时手动选择 |
| API Key | 你的 Key（每个服务商单独保存在钥匙串中）；Ollama、LM Studio 等本机服务可不填 |
| 模型 | 点击「测试连接」后选择接口返回的模型，或手动填写服务商支持的模型 ID |
| 上下文窗口 | 接口报告时自动采用，否则按 128K 计算；也可按服务商的模型说明手动选择 |

模型列表由接口返回结果和当前选择组成，不再预设模型名称；开始对话前需选择或填写模型。保存了多个服务商时，也可以在 AI 面板顶部的模型菜单中切换。

Kimi 开放平台默认开启「缓存保留 1 小时」：缓存从默认的 5 分钟延长到 1 小时，首次写入贵一些，但一小时内的提问都能命中缓存。

「设置 → 讲解 → 上下文上限」用滑块设定每次请求最多占模型上下文窗口的比例（20%–90%，默认 80%），其余留给回答；课件或对话超出时，保留当前页附近的课件和最近的对话。

| 模板 | API 地址 | 说明 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | 可开关深度思考 |
| Kimi Code（会员订阅） | `https://api.kimi.com/coding/v1`（海外账号：`https://api.kimi.ai/coding/v1`） | Key 在 Kimi Code 控制台创建；默认模型 `kimi-for-coding`；可调思考强度 |
| Kimi 开放平台（按量付费） | `https://api.moonshot.cn/v1` | |
| 其他 OpenAI 兼容接口 | 自行填写 | |

> Kimi Code 会员权益面向编程场景，官方可能只允许编程工具调用；被拒绝（HTTP 403）时可改用 Kimi 开放平台的 Key。

请求被拒绝时会判断原因并自动重试：模型不支持图片就不再发送截图；上下文超长时记下真实上限；`max_tokens` 超出范围或某个参数不被接受时记下来，之后不再发送。限流、服务端临时故障和连接中断，在还没有输出时会自动重试。检测到的结果显示在「设置 → 模型 → 自动检测到的限制」，可以重置。

## 快捷键

以下为默认快捷键，可在「设置 → 快捷键」中修改（点按快捷键后按下新的组合；⌫ 清除，esc 取消）。

| 操作 | 快捷键 |
|---|---|
| 打开课程文件夹 | ⌘O |
| 讲解当前页 | ⌘E |
| 提问（聚焦输入框） | ⌘L |
| 上一页 / 下一页 | ⌥⌘↑ / ⌥⌘↓ |
| 放大 / 缩小 / 适合窗口 | ⌘= / ⌘- / ⌘0 |
| 停止生成 | ⌘. |
| 显示 / 隐藏侧栏、AI 面板 | ⌃⌘S / ⌥⌘0 |
| 学习统计 | ⇧⌘S |
| 设置 | ⌘, |

总结课件、知识框架、练习题、翻页自动讲解、深度思考和连续滚动默认没有快捷键，可自行设置。

在课件中选中文字会出现工具条（解释 · 翻译 · 举例 · 提问）；点击回答中的「第 N 页」可直接跳转。

## 隐私

- 课程文件夹始终只读。
- 发送给模型服务的内容：课件文字、当前页码与截图、选中内容、最近的对话。
- API Key 存于系统钥匙串 · 对话记录与学习统计：`~/Library/Application Support/PPTReader` · 缓存：`~/Library/Caches/PPTReader`
- 学习统计只保存在本机，可在「设置 → 数据」中清除。

## 目录结构

```
Sources/PPTReader/
  App/        应用入口、菜单命令
  Models/     全局状态、当前课件、对话逻辑
  Services/   API 客户端、提示词、Office 转换、文字提取 / OCR、设置、快捷键、学习统计、多语言
  Views/      窗口布局、侧栏、阅读区、AI 面板、菜单、设置、学习统计、图表预览
Resources/Web/  回答渲染页与图表预览（markdown-it、KaTeX、highlight.js、DOMPurify、Mermaid，离线打包）
scripts/        build-app.sh · fetch-vendor.sh · make-icon.swift
```
